# Sudoku-solver
This project implements a Sudoku Solver using the Backtracking Algorithm in Java.
The program takes a 9×9 Sudoku grid as input (with 0 representing empty cells) and fills the board with a valid solution following Sudoku rules.

🚀 Features
✔ Solves any valid 9×9 Sudoku grid
✔ Uses Backtracking algorithm
✔ Checks for row, column, and 3×3 box constraints
✔ Clean and modular code (isSafe, solver, printer)
✔ Works for partially filled puzzles
✔ Prints the completed Sudoku grid
